# 🔐 WastleTempMailBot

🇺🇸 **English Documentation** | [🇷🇺 Русская документация](./README_ru.md)

---

**WastleTempMailBot** is a high-performance, secure Telegram Bot and Telegram Mini App (TMA) built as a core service of the **Wastle Ecosystem**. It provides instant, anonymous temporary email addresses with real-time push notifications and live webmail synchronization directly inside Telegram.

👉 **[Launch WastleTempMailBot in Telegram](https://t.me/WastleTempMailBot)**

---

## ✨ Key Features

* 🌐 **Bilingual Localization:** Full Russian and English support with persistent user preference storage.
* ⚡ **Real-Time Push Notifications:** Instant Telegram chat notifications the moment verification codes or emails arrive.
* 📱 **Telegram Mini App (TMA):** Modern dark-mode mobile web interface built with Tailwind CSS and Telegram WebApp SDK, featuring live 15-minute UTC countdown timers and one-click copy.
* 🛡 **Secure & Private:** Full confidentiality with zero personal data tracking.
* 🔄 **Live Webmail Synchronization:** Real-time updates streamed seamlessly via Server-Sent Events (SSE).
