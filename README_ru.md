# 🔐 WastleTempMailBot

[🇺🇸 English Documentation](./README.md) | 🇷🇺 **Русская документация**

---

**WastleTempMailBot** — это высокопроизводительный Telegram-бот и Telegram Mini App (TMA) профессионального уровня, разработанный как ключевой сервис экосистемы **Wastle**. Он предоставляет защищенные, анонимные временные почтовые ящики с мгновенными пуш-уведомлениями и синхронизацией веб-интерфейса в реальном времени.

---

## 🏗 Архитектурный обзор

Проект построен на базе **двухпоточной параллельной архитектуры**, работающей на едином асинхронном цикле событий Python (`asyncio`):
1. **Ядро Telegram-бота (`aiogram 3`):** Асинхронный интерфейс методом long-polling с поддержкой двуязычной локализации (RU/EN), интерактивными клавиатурами и командами (`/start`, `/status`, `/webapp`).
2. **Сервер веб-приложения (`aiohttp`):** Встроенный веб-сервер, одновременно обслуживающий Telegram Mini App (TMA) и REST/SSE API-эндпоинты параллельно с ботом.
3. **Поток событий в реальном времени (SSE):** Технология Server-Sent Events (`/api/stream/{user_id}`) транслирует обновления входящих писем во фронтенд мгновенно без лишней нагрузки от постоянного ополлинга.
4. **Отказоустойчивый сетевой слой:** Встроенная поддержка SOCKS5-прокси через `aiohttp-socks` для гарантированной стабильности в условиях сетевых ограничений.

---

## ✨ Ключевые особенности

* 🌐 **Двуязычная локализация:** Полная поддержка русского и английского языков с сохранением языковых предпочтений пользователя в базе данных.
* ⚡ **Мгновенные пуш-уведомления:** Фоновый воркер (`mail_watcher_worker`) автоматически проверяет активные ящики каждые 15 секунд и присылает новые письма прямо в чат Telegram.
* 📱 **Telegram Mini App (TMA):** Современный мобильный веб-интерфейс в темных тонах на Tailwind CSS и Telegram WebApp SDK с 15- минутным UTC-таймером обратного отсчета и копированием в один клик.
* 🛡 **Безопасный почтовый бэкенд:** Интеграция с Mail.tm API без необходимости настройки собственного почтового сервера (Postfix/MX).
* ⚙️ **Динамические миграции БД:** Асинхронная SQLite база данных с автоматической проверкой структуры таблиц через `PRAGMA table_info`.

## 🛠 Технический стек

* **Язык:** Python 3.11+ (Строгий Async/Await)
* **Фреймворк ботов:** `aiogram 3.3.0+`
* **Веб и API:** `aiohttp`, Server-Sent Events (SSE)
* **База данных:** SQLite + `aiosqlite`
* **Качество кода и тесты:** `ruff`, `pytest`, `pytest-asyncio`

## 🚀 Установка и запуск

### 1. Локальная разработка
1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. Настройте файл `.env`:
   ```env
   BOT_TOKEN=ваш_токен_бота_telegram
   PROXY_URL=socks5://127.0.0.1:10808   # Опционально: SOCKS5 прокси
   WEBAPP_URL=http://localhost:8080
   ```
4. Запустите приложение:
   ```bash
   python3 bot.py
   ```

### 2. Деплой в продакшн (Render.com)
Проект полностью готов к деплою на Render:
* **Runtime:** Python 3
* **Build Command:** `pip install -r requirements.txt`
* **Start Command:** `python3 bot.py`
* **Переменные окружения:** `BOT_TOKEN`, `WEBAPP_URL` (`https://ваш-сервис.onrender.com`), и системный `PORT`.
